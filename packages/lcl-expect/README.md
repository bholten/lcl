# lcl-expect

Expect-style automation of interactive programs: spawn, send, and match patterns with lexical handlers.

Build with `-DLCL_BUILD_EXPECT=ON` (requires `-DLCL_BUILD_PROCESS=ON`). POSIX only (pseudo-terminals via lcl-process); not portable to Windows.

Documentation: [docs/Expect.lcl](docs/Expect.lcl) — rendered on the docs site.
